# 07 · 参考标准基线（PRD 前置依据）

> 状态：✅ 已确认（2026-08）
> 结论：**赛道有成熟参考标准，四层齐备；自主完成能力经实测评估过关。PRD 可直接引用本基线作为需求合理性依据。**

## 问题一：有无可参考的标准？——有，四层

### 产品层：功能基线

| 参考对象 | 可对标内容 | 现状 |
|---|---|---|
| Elicit / SciSpace / Consensus | 搜索 → 摘要 → 问答 → 引用的产品形态 | 成熟商业模式验证需求 |
| 秘塔 / AMiner | 中文体验 + 结构化组织答案 | 验证中文用户价值 |
| arxiv-sanity | arXiv 原生工具浏览/筛选交互 | 2021 停更 → 换代窗口 |
| WisPaper | AI Feeds 每日追踪 | 验证推送是差异化方向 |

### 技术层：实现基线（开源标杆）

| 参考实现 | Stars | 可借鉴 |
|---|---|---|
| paper-qa | 9.0k | 引用溯源 RAG 行业标杆：架构、检索流程、引用格式 |
| gpt-researcher | 28.8k | Agent 编排、多步骤研究流程 |
| litellm | — | 多模型接入层（已装） |

### 评测层：效果基线

| 基准 | 用途 |
|---|---|
| LitQA（paper-qa 论文提出） | 科学文献问答评测标准，量化检索+回答质量 |
| SciSpace 200 queries 评测法 | N 个跨领域问题 + 多模型打分评相关性，方法可复用 |
| 引用溯源率 | 核心指标：回答必须带可核验来源（验收标准 100%） |

### 差异化锚点

竞品全都不做「个人领域追踪」——Consensus 用户亲口问"有没有个人存储和检索"。需求真实、竞品空缺、路径已被 paper-qa 验证。

## 问题二：无参考时能否自主完成？——具备（实测依据）

| 能力项 | 依据 |
|---|---|
| 开发环境 | Python 3.12 + uv + 依赖全就绪（缺 chromadb/streamlit，uv 一条命令可装） |
| 数据源 | arXiv API 实测 200，0.37s 响应 |
| 模型 | deepseek key 已配；embedding 走 ModelScope（实测可达；hf 源不通已有替代） |
| 算力 | RTX 3060 6GB 可跑本地 embedding |
| 实现路径 | RAG 链路是 2024-2026 最成熟应用模式，全开源组件，无自研算法风险 |

## 关键风险预判

| 风险 | 概率 | 对策 |
|---|---|---|
| 检索质量不达标 | 中 | LitQA 风格 20 问评测集量化，不达标调 chunk/embedding/top-k |
| embedding 模型下载失败 | 低 | hf 源已确认不通，ModelScope 已确认可达（200） |
| 部署不稳定 | 低 | Streamlit Cloud 免费层够用；缓存兜底限流 |
| 成本超支 | 低 | deepseek 便宜 + 本地 embedding，月成本估算 ¥3~6 |

## 结论

PRD 有明确基线可对标，不需要从零验证基础逻辑；能力评估过关。PRD 引用本基线作为「需求合理性依据」。
