你是资深产品设计师 + 前端工程师。为一个 B端/AI 科研工具做高保真可交互 HTML 原型，3 个页面，单文件 index.html（CSS/JS 全内联），中文界面。

## 产品
论文情报 Agent（Paper Radar）：给时间稀缺的领域追踪者一个情报雷达，输入研究主题后 10 分钟掌握该领域一周进展。核心卖点：引用溯源防编造（无来源不回答）、领域趋势雷达、中文结构化摘要。

## 目标用户
AI 方向研究生、工程师、产品经理。会用 arXiv、读过英文论文、讨厌信息过载。产品气质要像 Elicit/Consensus 一样有学术可信度。

## 设计定案（先按这个做，别改）
- 气质：Apple 式冷静科研风，极简高级，大量留白，内容为王。参考苹果官网的干净、克制、可信。
- 配色（经典苹果白）：
  - 页面底色：纯白 #ffffff，浅灰分段背景 #f5f5f7
  - 主文字：近黑 #1d1d1f
  - 次要文字：灰 #6e6e73
  - 主色（链接/按钮/强调）：苹果蓝 #0071e3
  - 成功绿 #34c759，警告橙 #ff9500
  - 边框：浅灰 #d2d2d7
  - 卡片：白底 #ffffff + 1px #d2d2d7 边框 + 极淡阴影（rgba 0,0,0,0.04）
- 字体：系统字体栈（-apple-system, "SF Pro Text", "Helvetica Neue", "PingFang SC", "Microsoft YaHei", sans-serif），标题 600 字重，正文 14px，数字/编号用等宽字体（tabular-nums / SF Mono）
- 组件：手写 CSS，不用任何框架；按钮、卡片、状态标签、趋势图都要像真实产品
- 动效：只做一个——趋势图曲线绘制动画（SVG stroke-dashoffset 描边动画，数据点逐个浮现），其余全部静态
- 布局：桌面 1440 宽，顶部简洁导航（logo + 页面切换），内容区居中 max-width 1100px

## 页面 1：首页（搜索入口）
- 顶部导航：logo「Paper Radar」+ 三个页面切换按钮（雷达 / 论文 / 问答），当前页高亮苹果蓝
- Hero 区：巨大标题「你的领域，10 分钟掌握一周进展」+ 副标题一行小字
- 居中大搜索框：placeholder「输入研究主题，如：Retrieval-Augmented Generation」，右侧苹果蓝圆形搜索按钮
- 搜索框下方 3 个热门主题标签（可点击）：RAG / AI Agents / Multimodal LLM
- 页面底部浅灰区放 3 个能力卡片：「引用溯源 · 绝不编造」「领域雷达 · 趋势感知」「中文摘要 · 高效消化」，各配一个简洁 SVG 图标
- 点击搜索按钮或标签 → 跳到页面 2 并触发搜索状态

## 页面 2：领域雷达（搜索结果 + 趋势 + 论文列表）
- 顶部导航同页面 1
- 顶部一行：当前主题「Retrieval-Augmented Generation」+ 「近 30 天 · 146 篇新论文」+ 状态标签（绿色「数据已更新」）
- 左侧 1/3：趋势面板「论文数量趋势」
  - SVG 折线图，曲线绘制动画，横轴日期（8/1~8/31 若干刻度），纵轴论文数
  - 下方高频关键词标签云：RAG 42 / retrieval 38 / hallucination 25 / knowledge graph 18 / agent 15 等，字号随频次大小
- 右侧 2/3：论文列表（结构化摘要卡片）
  - 每张卡片：论文标题（点击可展开）、作者 + 日期 + arXiv ID 灰色小字、四段式标签（问题 / 方法 / 结论 / 创新点 各一行小字）、右上「相关文献」小按钮
  - 3~4 张卡片示例，中文摘要内容用真实行业风格（检索增强生成、知识图谱、幻觉消减等）
  - 卡片 hover 轻微上浮 1px，边框变浅蓝

## 页面 3：深度问答（引用溯源）
- 顶部导航同页面 1
- 左侧 2/3：对话区
  - 顶部问题输入框：placeholder「就当前主题提问，如：RAG 的幻觉问题主要怎么解决？」
  - 示例对话 2 轮：用户问 → AI 答（回答段落中关键句带蓝色引用角标 [1] [2]）
  - 回答下方引用卡片：来源论文标题 + arXiv 链接（蓝色可点），卡片浅灰底
- 右侧 1/3：问答说明面板
  - 「无来源不回答」规则卡片（苹果蓝边框）：本产品所有回答均附带来源论文，检索不到相关内容时会明确提示，绝不编造
  - 提问建议 3 条（灰色小字列表）
- 对话底部：绿色状态「已连接知识库 · 146 篇论文」
